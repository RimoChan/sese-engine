# Legacy Files

这个目录包含了原始 sese-engine 的中文文件名代码文件。这些文件已经被重构为现代化的架构并移动到 `src/` 目录中。

## 文件映射

| 原文件名 | 新位置 | 说明 |
|---------|--------|------|
| `人服务器.py` | `src/api/` | FastAPI 搜索服务器 |
| `上网.py` | `src/crawler/` | 网页爬虫模块 |
| `存储.py` | `src/storage/` | 数据存储层 |
| `配置.py` | `src/config/` | 配置管理 |
| `utils.py` | `src/utils/` | 工具函数 |
| `信息.py` | `src/metrics/` | 指标和统计信息 |
| `网站.py` | `src/sites/` | 网站信息管理 |
| `分析.py` | `src/analyzer/` | 文本分析模块 |
| `文.py` | `src/scraper/` | 网页抓取工具 |
| `虫.py` | `src/crawler/` | 爬虫核心逻辑 |
| `回.py` | `src/indexer/` | 索引管理器 |
| `收获服务器.py` | `src/harvester/` | 数据收集服务器 |
| `打点.py` | `src/monitoring/` | 监控和指标收集 |
| `类.py` | `src/types.py` | 类型定义 |
| `启动.sh/.cmd` | `start.sh/.bat` | 现代化启动脚本 |

## 主要改进

1. **模块化架构** - 拆分为独立的模块和包
2. **英文命名** - 所有函数、变量、类都改为英文
3. **类型安全** - 添加完整的类型提示
4. **现代框架** - 使用 FastAPI 替代 Flask
5. **测试驱动** - 添加完整的单元测试
6. **文档完善** - 详细的文档和API说明

## 兼容性

这些原始文件保留在这里是为了：
- 参考原始实现逻辑
- 兼容性对比
- 逐步迁移参考

新的实现应该使用 `src/` 目录中的现代化模块。
